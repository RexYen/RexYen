# Hi, I'm Rex

**Product manager & product designer.** I turn product ideas into running software, and I build it by directing AI agents.

### What I do

- **Prototype as spec.** I build working prototypes so product decisions get made on real screens, not slides.
- **Ship the small production surfaces myself:** campaign pages, a members-only storefront, transactional email and paywall configuration. I design, build and operate them end to end with AI.
- **Own the rules behind the screens:** subscription lifecycles, eligibility, state machines, notification logic.

### How I build

- Claude Code, Codex and Claude Design, each routed by role: plan, build, review.
- Parallel agents in separate git worktrees, with human gates before merge and deploy.
- Skills that write team know-how down, so the next person (or agent) gets it right.

**Stack I ship on:** Next.js · React · TypeScript · Tailwind · Supabase · Vercel · Mailgun · RevenueCat · BigQuery · Amplitude · Figma

### Open source

- [**edm-review**](https://github.com/RexYen/edm-review): a Claude Code skill that reviews transactional email HTML in plain language for marketers. It covers Gmail `<style>` stripping, Outlook rendering engines and dark mode.
- Contributions to [greensock/gsap-skills](https://github.com/greensock/gsap-skills) and a stock-hypothesis-tree skill set.
